# Стёкла для духовых шкафов и плит (Челябинск) — СТЁКЛА174

Лендинг для компании по подбору и изготовлению жаростойких стёкол для духовых шкафов и плит в Челябинске.

Сайт полностью статичен (чистый HTML5, CSS3, JavaScript без сторонних тяжелых библиотек и сборщиков) и оптимизирован для хостинга на **GitHub Pages**.

---

## 📁 Структура проекта

- `index.html` — главная страница сайта (точка входа для GitHub Pages).
- `site.css` — стили, адаптивная вёрстка, стилизация интерактивных элементов и компонентов без картинок.
- `site.js` — интерактивные функции: фильтрация каталога, слайдер сравнения стёкол «до/после», счётчики, мобильное меню, аккордеон.
- `.nojekyll` — сообщает GitHub Pages, что проект не требует сборки Jekyll.

---

## 🚀 Инструкция по публикации на GitHub Pages

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com/) и создайте новый публичный репозиторий (например, `siteokna` или `stekla174`).
2. Оставьте галочки «Add README» и «.gitignore» пустыми.

### Шаг 2. Загрузите файлы в репозиторий
Выполните следующие команды в папке проекта (в терминале PowerShell / Git Bash):

```bash
git init
git add .
git commit -m "Подготовка сайта для GitHub Pages"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

*(Или просто перетащите файлы через браузер с помощью кнопки **Add file -> Upload files** на странице репозитория).*

### Шаг 3. Включите GitHub Pages
1. Откройте ваш репозиторий на GitHub.
2. Перейдите в **Settings** (Настройки) -> вкладка **Pages** (в левом меню).
3. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`.
   - **Branch**: выберите ветку `main` и папку `/(root)`.
4. Нажмите **Save**.

Через 1–2 минуты сайт станет доступен по адресу:
`https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`
